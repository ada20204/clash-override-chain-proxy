# Clash 完全覆写脚本低门槛配置教程

这篇教程面向第一次使用 Clash Party / Mihomo Party 覆写的人。你不需要理解脚本源码，只要按自己的情况导入文件，并修改少量配置项即可。

> 当前文档由飞书教程内容整理而来，并按仓库当前脚本功能同步更新。飞书里的截图和 callout 已转换为 GitHub Markdown，避免图片 token 或飞书专有标签在 GitHub 上渲染失败。

## 这个脚本解决什么问题

这个项目会在你的订阅配置上自动补齐代理组、分流规则和 DNS 配置。最低门槛用法是只导入 `完全覆写.js`，不配置家宽 IP、不配置自定义出口，也可以获得功能组、域名规则、国内直连和兜底节点选择。

| 场景 | 脚本会怎么处理 |
|---|---|
| YouTube、Netflix、Twitter、Spotify 等 | 走 `🌍 国际媒体` 组 |
| Telegram、Discord | 走 `📲 Telegram` 组 |
| GitHub、GitHub Copilot | 走 `🐙 GitHub` 组 |
| Microsoft、Office、Bing、Xbox、VS Code | 走 `Ⓜ️ 微软服务` 组 |
| Steam、Epic、Nintendo、PlayStation | 走 `🎮 游戏平台` 组 |
| Apple、iCloud、App Store | 走 `🍎 Apple` 组 |
| 国内网站和国内 IP | 自动直连 |
| Claude、ChatGPT、Cursor、Codex 等 AI 工具 | 走独立的 `🤖 AI Agent` 组 |

## 先选你的使用模式

| 你想实现什么 | 需要导入哪些文件 | 适合谁 |
|---|---|---|
| 只想自动分流，不折腾家宽 IP | 只导入 `完全覆写.js` | 新手、普通代理订阅用户 |
| 想解决本机网络到订阅节点污染或超时 | 先导入 `前置代理.js`，再导入 `完全覆写.js` | 有上海/国内云服务器代理的人 |
| 想让 AI 工具走美国静态家庭 IP | 先导入 `出口IP凭证.js`，再导入 `完全覆写.js` | 有静态家庭 IP 或家宽代理的人 |
| 想额外加入自己的 HTTP/SOCKS5 出口节点 | 先导入 `出口IP凭证.js`，再导入 `完全覆写.js` | 有公司代理、备用出口、自建代理的人 |

如果同时使用前置代理和出口凭证，推荐顺序是：

```text
1. 前置代理.js
2. 出口IP凭证.js
3. 完全覆写.js
```

顺序不能反。前两个脚本负责把配置塞进 `config`，主脚本 `完全覆写.js` 再读取它们并生成代理组和规则。

## 你需要准备什么

- 已安装 Clash Party 或 Mihomo Party
- 已经有一个可用订阅
- 知道如何进入软件里的「覆写」或「Override」列表
- 从本仓库下载脚本文件：
  - 必选：[`src/完全覆写.js`](../src/完全覆写.js)
  - 可选：[`src/前置代理_样本.js`](../src/前置代理_样本.js)
  - 可选：[`src/出口IP凭证_样本.js`](../src/出口IP凭证_样本.js)

## 方式一：纯分流模式

适合只想让订阅配置更好用的人：自动分组、自动分流、国内直连。

1. 打开仓库里的 `src/完全覆写.js`
2. 下载到本地
3. 在 Clash Party / Mihomo Party 的「覆写」列表里新增 JavaScript 覆写
4. 选择或粘贴 `完全覆写.js`
5. 启用覆写，回到订阅配置重新应用

导入成功后，代理组里会出现类似这些分组：

```text
自动选择
节点选择
GLOBAL
🌍 国际媒体
📲 Telegram
🐙 GitHub
Ⓜ️ 微软服务
🎮 游戏平台
🍎 Apple
🎯 直连
🤖 AI Agent
🇭🇰|香港
🇺🇸|美国
🇯🇵|日本
🇨🇳|台湾
```

如果你只需要普通分流，到这里就完成了。

## 方式二：配置前置代理

前置代理适合本机所在网络到订阅节点 DNS 污染严重、晚高峰 URLTest 大面积超时，或者希望先从上海/国内云服务器出站，再连接订阅里的外部节点。

1. 复制 [`src/前置代理_样本.js`](../src/前置代理_样本.js)
2. 重命名为 `前置代理.js`
3. 取消注释 `config._frontProxy`
4. 填入你的前置代理地址和端口

示例：

```javascript
function main(config) {
  config._frontProxy = {
    name: "上海阿里云前置",
    type: "socks5",
    server: "你的上海云服务器IP",
    port: 1080
  };

  return config;
}
```

配置后，订阅原始节点会先走这个前置代理；URLTest 测速地区节点时也会先走前置代理。自定义出口、家宽 IP 和 DIRECT 不会被前置代理覆盖。

> 前置代理不是最终出口，不会出现在 `节点选择` 或 `🤖 AI Agent` 里。它更像是所有订阅节点前面的第一跳。

## 方式三：配置美国静态家庭 IP

适合你有一个自己的家宽 HTTP/SOCKS5 代理，或者通过静态住宅 IP 服务购买了固定美国出口，并希望 AI 工具流量走这个出口。

配置后，脚本会新增：

| 新增内容 | 作用 |
|---|---|
| `家宽IP` 节点 | 你的家宽 HTTP/SOCKS5 出口 |
| `🔗 家宽跳板` 组 | 决定家宽节点前面走哪条订阅线路 |
| `🏠家宽IP` 组 | 可被 `🤖 AI Agent` 选择的家庭 IP 出口 |

### 复制凭证样本

复制 [`src/出口IP凭证_样本.js`](../src/出口IP凭证_样本.js)，重命名为：

```text
出口IP凭证.js
```

### 填写家宽 IP 信息

打开 `出口IP凭证.js`，找到 `config._homeProxy`，取消注释并填入真实信息：

```javascript
function main(config) {
  config._homeProxy = {
    type: "socks5",
    server: "你的家宽IP或域名",
    port: 1080,
    username: "你的账号",
    password: "你的密码"
  };

  return config;
}
```

字段说明：

| 字段 | 怎么填 |
|---|---|
| `type` | `http` 或 `socks5` |
| `server` | 家宽代理的 IP 或域名 |
| `port` | 家宽代理端口，例如 `1080`、`7890` |
| `username` | 如果代理需要账号，再填写 |
| `password` | 如果代理需要密码，再填写 |

不要把填写了账号密码的 `出口IP凭证.js` 上传到公开仓库。这个文件应该只保存在你自己的电脑里。

## 方式四：添加自定义出口节点

如果你还有额外 HTTP/SOCKS5 出口，可以写到 `config._customProxies`。这些节点会被注入到代理节点里，并出现在相关选择组中。

示例：

```javascript
function main(config) {
  config._customProxies = [
    {
      name: "自定义出口",
      type: "http",
      server: "10.0.0.1",
      port: 3128
    },
    {
      name: "公司代理",
      type: "socks5",
      server: "10.0.0.2",
      port: 1080
    }
  ];

  return config;
}
```

如果自定义出口也需要账号密码，继续追加：

```javascript
{
  name: "带认证的出口",
  type: "http",
  server: "example.com",
  port: 3128,
  username: "你的账号",
  password: "你的密码"
}
```

## AI Agent 组怎么理解

`🤖 AI Agent` 是 AI 域名和 AI 进程的独立策略组。它不会直接放入总的 `自动选择` 组，因为 AI 出口通常需要更明确、更稳定。

有家宽 IP 时：

```text
🏠家宽IP / 节点选择 / 地区组 / 自定义出口 / DIRECT
```

无家宽 IP 时：

```text
节点选择 / 地区组 / 自定义出口 / 订阅裸节点 / DIRECT
```

这里的关键点是：

- 有家宽 IP 时，AI Agent 里不展开订阅裸节点，避免高阶场景下列表过长
- 无家宽 IP 时，保留订阅裸节点，方便单独给 AI 选择某个支持 AI 的节点
- 地区组会保留，例如 `🇺🇸|美国`、`🇭🇰|香港`、`🇨🇳|台湾`
- 总的 `自动选择` 不放进 AI Agent，避免 AI 出口选择过于含糊

## 常用参数怎么改

`完全覆写.js` 顶部有一段 `USER_OPTIONS`：

```javascript
var USER_OPTIONS = {
  autoSelectGroupName: "自动选择",
  enableChainRegionBrowserProcessProxy: false,
  enableChainRegionAiCliProcessProxy: true
};
```

一般只需要理解这三个：

| 参数 | 默认值 | 什么时候要改 |
|---|---:|---|
| `autoSelectGroupName` | `自动选择` | 如果你的订阅自动测速组不叫「自动选择」，就改成你的组名 |
| `enableChainRegionBrowserProcessProxy` | `false` | 想让 Chrome、Edge、Dia、Atlas 等浏览器也走 AI Agent 时改为 `true` |
| `enableChainRegionAiCliProcessProxy` | `true` | 想让 Claude Code、Gemini CLI、Codex CLI 等 AI 命令行工具走 AI Agent，保持 `true` |

如果不知道要不要改，就先保持默认。默认配置更稳：AI 工具走独立组，浏览器不强制走 AI Agent。

## 如何申请美国静态家庭 IP

这里以 Cliproxy 为例。官网地址：[https://cliproxy.com/zh/](https://cliproxy.com/zh/)

> 购买前请自行确认所在地、用途和合规要求。服务页面、价格、地区和产品命名可能会变化，实际信息以 Cliproxy 页面显示为准。

### 进入长效静态 IP 页面

打开 Cliproxy 官网后，可以从顶部或价格区进入：

```text
价格 → 长效静态IP
```

也可以尝试直接打开：

```text
https://cliproxy.com/zh/pricing/static-isp/
```

教程整理时，页面标题为「独享长效静态ISP价格」，页面关键信息包括家庭原生 IP、独享使用、不限流量、不提取不计时、99% 成功率等。价格会按地区和购买时长变化。

### 选择美国地区

在长效静态 IP 价格表里选择：

```text
美国
```

然后根据页面提供的选项选择有效期，例如：

```text
7 天 / 30 天 / 90 天
```

购买前确认：

- 选择的是「长效静态 IP」或「静态 ISP」类产品
- 地区选择的是美国
- 账号能正常登录 Dashboard
- 余额或付款方式可用

### 购买并复制连接信息

购买完成后，进入 Dashboard 的静态 IP 使用列表，通常需要拿到这四项：

| Cliproxy 字段 | 填到脚本里的字段 |
|---|---|
| Host / Server | `server` |
| Port | `port` |
| Username | `username` |
| Password | `password` |

### 先用命令测试代理是否可用

如果电脑上可以使用命令行，建议先测试一次，避免直接填进 Clash 后不好排查。

SOCKS5 示例：

```bash
curl --proxy socks5://username:password@Host:Port https://mayips.com
```

HTTP 示例：

```bash
curl --proxy http://username:password@Host:Port https://mayips.com
```

把 `username`、`password`、`Host`、`Port` 换成 Cliproxy 使用列表里的真实信息。如果返回的 IP 信息显示为美国，说明这个静态家庭 IP 可以正常使用。

### 填入出口凭证

如果 Cliproxy 给的是 SOCKS5，就这样填：

```javascript
function main(config) {
  config._homeProxy = {
    type: "socks5",
    server: "Cliproxy 给你的 Host",
    port: 12345,
    username: "Cliproxy 给你的 Username",
    password: "Cliproxy 给你的 Password"
  };

  return config;
}
```

如果 Cliproxy 给的是 HTTP 代理，就把 `type` 改成 `http`。注意 `port` 是数字，不要加引号。

## 如何验证出口是否正确

打开 Clash Party 左侧「网络信息」，右上角可以切换检测源。当前脚本会显式分流三个检测源：

| 检测源 | 用来判断什么 | 规则目标 | 预期结果 |
|---|---|---|---|
| `ipapi.is` | AI 专用出口 | `🤖 AI Agent` | 显示 AI Agent 当前选择的出口；如果选了 `🏠家宽IP`，就显示家宽 IP |
| `ipwho.is` | 普通代理出口 | `节点选择` | 显示常规代理节点出口，不受 AI Agent 单独选择影响 |
| `IP.SB` / `ip.sb` | 前置链路或直连出口 | 有前置代理时指向前置代理；无前置代理时 `DIRECT` | 开启前置代理时显示上海/国内云服务器 IP；未开启时显示本机直连公网 IP |

简单判定方式：

```text
ipapi.is → 看 AI 相关流量最终走哪里
ipwho.is → 看普通代理节点最终走哪里
ip.sb    → 看本机到订阅节点前的第一跳；没前置代理时就是直连公网 IP
```

如果你要验证美国静态家庭 IP：

1. Clash Party 保持规则模式
2. TUN / 虚拟网卡保持开启
3. `出口IP凭证.js` 排在 `完全覆写.js` 前面
4. 在 `🤖 AI Agent` 里选择 `🏠家宽IP`
5. 打开「网络信息」，选择 `ipapi.is` 并刷新
6. 重点看国家/地区是否为 United States / 美国

如果你要验证前置代理：

1. `前置代理.js` 排在 `完全覆写.js` 前面
2. 重新应用订阅配置
3. 打开「网络信息」，选择 `IP.SB` 并刷新
4. 期望看到上海/国内云服务器的公网 IP

如果配置了 `前置代理.js`，地区组和 URLTest 测速订阅节点时会先走前置代理，因此 `IP.SB` 应显示前置代理 IP；但 `ipwho.is` 仍应显示普通代理节点的最终出口 IP。

## 与 Tailscale 共存

脚本默认按标准 Tailscale 方式共存，不接管 Tailscale Exit Node 的转发流量。

脚本会让这些内容保持直连：

```text
Tailscale 进程 → DIRECT
100.64.0.0/10 → DIRECT
100.100.100.100/32 → DIRECT
fd7a:115c:a1e0::/48 → DIRECT
```

这样做是为了避免 Tailscale 的 WireGuard / DERP / MagicDNS 流量被 Clash 再代理一层，导致套娃或断联。

如果远程设备使用这台机器作为 Tailscale Exit Node，建议按 Tailscale 官方方式配置 Exit Node。本脚本不保证这类转发流量进入 Clash 规则。若远程设备也需要使用 Clash 分流，更稳定的方式是让远程设备通过 Tailscale 访问本机 Clash 的 HTTP/SOCKS 代理端口。

## 常见问题

### 不配置家宽 IP 能用吗？

可以。只导入 `完全覆写.js` 时，脚本会进入纯分流模式，不会创建家宽节点，但 `🤖 AI Agent` 仍然会出现。你可以在里面选择地区组、自定义出口、订阅裸节点或 DIRECT。

### 为什么我没有看到 `🏠家宽IP`？

通常是因为没有正确导入 `出口IP凭证.js`，或者导入顺序错了。确认顺序是：

```text
出口IP凭证.js
完全覆写.js
```

如果同时用了前置代理，则是：

```text
前置代理.js
出口IP凭证.js
完全覆写.js
```

### 为什么 `🤖 AI Agent` 里没有自动选择？

这是有意设计。AI 出口通常需要固定国家、固定节点或固定家宽 IP；总的 `自动选择` 可能随测速变化，容易导致 AI 账号或 API 出口不稳定。地区组仍然会保留。

### 台湾为什么显示 `🇨🇳|台湾`？

脚本会使用中国旗标显示台湾地区组，避免在代理组里出现不符合预期的图标。分组名称仍然保留 `台湾`，方便识别节点地区。

### 我的自动选择组不叫「自动选择」怎么办？

打开 `完全覆写.js`，修改：

```javascript
autoSelectGroupName: "自动选择"
```

把 `自动选择` 改成你订阅里真实的自动测速组名称。

### 浏览器要不要强制走 AI Agent？

默认不要。浏览器流量很复杂，全部强制到 AI Agent 可能影响普通网页体验。只有你明确需要浏览器也使用 AI Agent 时，再把下面这个参数改成 `true`：

```javascript
enableChainRegionBrowserProcessProxy: true
```

### AI 工具包括哪些？

脚本覆盖了常见 AI 应用和命令行工具，例如 Claude、Claude Code、ChatGPT、Perplexity、Cursor、Antigravity、Gemini CLI、Codex CLI 等。macOS 和 Windows 的常见进程名都已覆盖。

## 新手推荐的最终方案

第一次使用，建议按这个顺序来：

1. 先只导入 `完全覆写.js`，确认分流正常
2. 如果本机到订阅节点经常全红，再添加 `前置代理.js`
3. 如果确实需要 AI 工具走美国静态家庭 IP，再添加 `出口IP凭证.js`
4. 最后再考虑自定义出口和浏览器强制 AI Agent

核心记忆点：主脚本是 `完全覆写.js`；凭证脚本和前置代理脚本都是可选的；需要它们时，必须排在主脚本前面。
