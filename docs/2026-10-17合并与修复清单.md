## 修复与回归

- 前置副本只解除脚本自动添加的上游，不绕过显式 via 或订阅原有 dialer-proxy；与节点/组重名时生成唯一编号。
- 全协议候选在所有组与前置副本创建后评估，检查全部可选链路，而非前置组默认项。不能证明 UDP 能力时不生成误导性的回退。
- Windows 本地盘符、UNC 与编码后的 file URL 使用系统路径解析；POSIX 权限测试与 Windows ACL 的能力边界分别说明。
- 家宽直连、链式节点保留 TLS；URI、附加字段和内嵌规则组统一解析秘密。缺少必需凭证不会覆盖旧输出。
- 订阅缓存按主机、订阅名、URL 和 User-Agent 隔离；旧名称缓存不再回退使用。离线需要原始来源身份。
- 跳板偏好只能选择原候选及其叶节点；runtime 后再次校验，拒绝自循环、缺失引用和专用出口混入。
- 修正 IP.SB 的旧说明：ip.sb 直连，ipip.net 前置，ipwho.is 节点选择，ipapi.is AI Agent。
